# Workshop 3: hands-on machine learning for trading

A presenter-led notebook that replicates Krauss, Do & Huck (2017), "Deep neural networks, gradient-boosted
trees, random forests: Statistical arbitrage on the S&P 500" (European Journal of Operational Research
259(2), 689-702; free version at https://www.econstor.eu/handle/10419/130166), on the S&P 100 from 2000 to
the last close, then takes the strategy to an Alpaca paper-trading account.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/michaelbolebrukh/quantsoc-ml-for-quant-finance/blob/workshop-3/workshop3/workshop3.ipynb)

On a campus network Colab can hit GitHub's rate limit when it opens a notebook from a link. If that happens,
open the notebook from a Google Drive copy instead (File, Upload notebook, or a shared Drive file).

## What is in here

| File | What it is |

## Paper-trading dashboard

A Streamlit page that runs the Krauss, Do & Huck (2017) strategy from `quantsoc_ml/statarb.py` on
today's prices: it scores every stock, picks the top k to buy and the bottom k to sell short, and
shows the orders that would move your account to that book. **Paper trading only**: it works with the
offline mock broker or your Alpaca PAPER account (practice money), and cannot reach a live account.

### Install

```bash
pip install streamlit alpaca-py python-dotenv
```

### Your Alpaca keys (only for Alpaca paper mode)

1. Log in at https://app.alpaca.markets, switch to **Paper Trading**, and create API keys.
2. In the repo root (the folder with `.env.example`), copy `.env.example` to `.env`.
3. Paste your PAPER keys after `APCA_API_KEY_ID=` and `APCA_API_SECRET_KEY=`.

`.env` is ignored by git. Never commit it, never paste keys into code. The dashboard only ever shows
*where* it found the keys, never the keys themselves.

### Run

From the repo root:

```bash
streamlit run workshop3/dashboard.py
```

Your browser opens at http://localhost:8501.

### The two modes (sidebar)

* **Offline demo** (the default when no keys are found): the committed price snapshot and a mock broker
  that already holds yesterday's book, so you see a real rebalance. Nothing leaves your computer and
  nothing can be submitted.
* **Alpaca paper**: prices and account data from your Alpaca PAPER account. Shows equity, cash, buying
  power, the market clock, today's signal, target weights, your positions against the targets, the
  proposed orders, your equity history and recent orders.

The strategy comes from `workspace/ws3/strategy.joblib` if you saved one there (the path is editable in
the sidebar); otherwise the page trains a random forest on the snapshot (about 10 seconds) and says so,
with the training dates.

Shorts: in Alpaca mode each short candidate is checked for borrow. A stock that is not shortable or not
easy to borrow is skipped and the next lowest-ranked stock is used; the page lists what was skipped.

### Safeguards

* The Submit button exists only in Alpaca paper mode, and only when the broker reports `paper=True`.
* You must tick "I understand this sends PAPER orders to Alpaca" **and** type `SUBMIT`.
* Nothing is ever sent on page load or refresh: only a click on the button sends orders.
* It refuses if any of the symbols already has an open order, or if the orders changed since the page
  was drawn.
* Exits and reductions are sent before new positions, so buying power is freed first.
* Each order's id is built from the decision date, the symbol and the leg (for example
  `qsml-ws3-20261015-BRK.B-open-short`). Alpaca refuses a reused id, so a double click cannot send an
  order twice. This also means one submission per decision date: if something was rejected, try again
  after the next trading day closes.
* Everything before the button (prices, scores, orders) runs through a read-only broker view that has
  no way to send an order.

Tickers: the strategy uses Yahoo tickers (`BRK-B`), Alpaca uses `BRK.B`. The dashboard converts both
ways for you.

Tests (no network): `python -m pytest tests/test_ws3_dashboard.py -q`.
